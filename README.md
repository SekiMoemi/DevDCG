# PROGRESS MASTER（開発カードゲーム）
* GitHub Pages URL : https://sekimoemi.github.io/DevDCG/

## 概要
### 目的
* gemini CLIでAI開発の勉強をする
* AIによるUI改修を含む調整を繰り返してみる
### 成果物
  * Unityで作ったゲーム
  * https://sekimoemi.github.io/DevDCG/
## 実施内容
### 役割分担
* 人：設計、素材の準備、Unity画面上での操作、動作確認、次の改修内容の検討
  * 開発は段階的プログラミングとして指示を出す（人の中では事前検討済みだが一気に作成させず、動く基本機能を作ってからその他仕様を実現していく）
* gemini：実装、人への作業依頼
  * mdファイルで仕様を読み、別のmdファイルに依頼書を作成する
### やったこと
  * UnityのUXML等を用いることでエディタによるUI実現を試す
    * 人間はゲームの設定やUIについて設計書を作成し、コーディングをAIに任せる
    * AIがロジックやデザインの実装を行い、Unity側で必要な操作や配置すべき素材についてAIに依頼書を作成する
    * 人間はAIの指示通りにアセットの配置や紐づけを行い、動作確認する
    * AIは人間の指摘に応じてコードを修正する
  * 機能追加や修正について段階的に開発し、やり取りが増えることによる情報の混乱の防ぎ方を考える
      * /chatで修正完了ごとにsaveし、修正の指示が上手く通らない場合は直前にsaveしたチャット状況に戻す
        * 不要な知識や作業が減る感じ、やり取りで調整できないなら一回リセットしてやり直した方が早い
        * コードもrestoreで一緒に戻した方が良い
      * 修正完了時はプロンプト上で「良い感じです！次は、」のように話題遷移を明示するような文言を加えてみる
        * なくても上手くいくことは多いが、似た修正だと以前の修正も確認されることがあるのであっても良さそう
